# API index

Every public function, method and type, with the first sentence of its docs. Generated by `cargo run -p api-index`; a test fails when it's out of date. Look here before writing a helper: the docs of each item are on docs.rs and in the source. Builder methods shared by all widgets are on `Styled`.

## dfui

### src/anim.rs

- `trait Lerp: Copy`: Values [`Animated`] can blend between.
- `Lerp::lerp(self, to: Self, t: f32) -> Self`: `self` at `t` 0, `to` at `t` 1, exact at both ends.
- `struct Animated<T>`: A value easing toward a target.
- `Animated::to(&self, to: T, now: Instant, duration: Duration, ease: fn(f32) -> f32)`: Eases from the current value to `to` over `duration`, starting at `now`.
- `Animated::get(&self, now: Instant) -> T`: The value at `now`.
- `Animated::running(&self, now: Instant) -> bool`: Still moving at `now`: keep requesting frames while it is.
- `struct Morph`: Morph between two [`Path`]s, e.g. two glyphs.
- `Morph::new(from: &Path, to: &Path) -> Self`: Pairs `from`'s contours and segments with `to`'s, as described above.
- `Morph::at(&self, t: f32) -> Path`: The outline at progress `t` (0 = `from`, 1 = `to`).

### src/icons.rs

- `fn menu() -> Shape`: Three bars, for a button that opens a menu or drawer.
- `fn back() -> Shape`: An arrow pointing left, for going back.
- `fn close() -> Shape`: A cross, for closing.

### src/kinetic.rs

- `struct Drag`: One axis of drag and fling.
- `Drag::down(&self, pos: f32, offset: f32, now: Instant)`: A press at `pos` with the content at `offset`; stops any fling.
- `Drag::moved(&self, pos: f32, now: Instant) -> Option<f32>`: The offset following the pointer once it has moved past the drag slop, `None` before (still a tap) or without a press.
- `Drag::up(&self, pos: f32, offset: f32, now: Instant) -> bool`: Release at `pos`; flings from `offset` if the pointer was moving fast.
- `Drag::cancel(&self)`: Drops the press, and with it the drag, without a fling.
- `Drag::stop(&self)`: Stops a fling, e.g. when the wheel or code moves the content.
- `Drag::shift(&self, d: f32)`: Moves the press's start offset and a fling's origin by `d`, for when the content moves under the drag (an item above it collapses).
- `Drag::pressed(&self) -> bool`: A press is down (a tap or a drag in progress).
- `Drag::flinging(&self) -> bool`: A fling started on release and hasn't ended or been stopped.
- `Drag::fling(&self, now: Instant, max: f32) -> Option<f32>`: Offset at `now` of a running fling, clamped to `0..=max`; the fling ends at an edge or once it's slow.

### src/lib.rs

- `trait App: 'static`: Root of the UI.
- `App::view(&self) -> Element`: Builds the whole UI.
- `App::theme(&self) -> Theme`: Colors for the whole app, read every frame.
- `App::background(&self) -> Color`: Window background, read every frame.
- `App::title(&self) -> String`: Desktop window title, read when the window opens.
- `App::fullscreen(&self) -> bool`: Opens the desktop window borderless fullscreen, e.g. for a TV.
- `App::zoom(&self) -> f32`: Multiplies the window's scale factor, so everything grows or shrinks, e.g. for a user's size setting.
- `App::hdr(&self) -> bool`: Shows bitmaps' values above 1.0 (from [`Bitmap::from_texture`] with `Rgba16Float`) brighter than SDR white, on screens that take HDR10.
- `fn run<A: App>(app: A)`: Opens a window showing `app` and runs until it's closed.
- `fn run_android<A: App>(app: A, android: AndroidApp)`: Runs `app` until the activity is destroyed; call it from `android_main`.

### src/model.rs

- `trait Keyed`: Stable identity of an item: rows keep their state and animate by it.
- `Keyed::key(&self) -> u64`: Unique among the model's items and unchanged while the item lives.
- `trait ListModel`: Items by index, each with a stable key.
- `ListModel::len(&self) -> usize`: Number of items.
- `ListModel::with<R>(&self, i: usize, f: impl FnOnce(&Self::Item) -> R) -> R`: Calls `f` with item `i`; `i` is below `len`.
- `ListModel::key(&self, i: usize) -> u64`: Key of item `i`; `i` is below `len`.
- `ListModel::is_empty(&self) -> bool`: Whether there are no items.
- `trait TreeModel`: Items addressed by key, each with ordered children.
- `TreeModel::children(&self, parent: Option<u64>, f: &mut dyn FnMut(u64))`: Calls `f` with the keys of `parent`'s children in order; `None` lists the roots.
- `TreeModel::with<R>(&self, key: u64, f: impl FnOnce(&Self::Item) -> R) -> R`: Calls `f` with the item under `key`, one the model has listed.
- `TreeModel::has_children(&self, key: u64) -> bool`: Lets a node show as expandable before its children are listed.
- `struct Tree<T>`: In-memory tree of [`Keyed`] items.
- `Tree::new() -> Self`: An empty tree.
- `Tree::push(&self, parent: Option<u64>, item: T) -> u64`: Adds `item` as the last child of `parent`, or as a root.
- `Tree::remove(&self, key: u64)`: Removes `key` and everything below it.
- `Tree::get(&self, key: u64) -> Option<&T>`: The item under `key`, if it's in the tree.
- `struct Row`: One visible row of a flattened tree.
- `fn flatten(model: &impl TreeModel, open: &HashSet<u64>) -> Vec<Row>`

### src/path.rs

- `type Point = [f32; 2]`: `[x, y]` in logical px, y down.
- `type Quad = [Point; 3]`: Quadratic Bézier segment: start, control, end.
- `struct Path`: Closed contours of quadratic segments in logical px (y down), filled by nonzero winding like a glyph.
- `Path::polygon(points: &[Point]) -> Path`: A single contour of straight edges through `points`.
- `Path::offset(self, dx: f32, dy: f32) -> Path`: The path moved by `dx`, `dy` logical px.
- `struct Stroke`: How [`stroke`] draws a line.
- `Stroke::new(width: f32) -> Stroke`: Square ends, bevelled bends.
- `Stroke::round(width: f32) -> Stroke`: Round ends, bevelled bends.
- `fn stroke(points: &[Point], s: Stroke) -> Vec<Vec<Point>>`: The line through `points` as polygons: a rectangle per segment, a triangle on the outside of each bend and half-disk caps, all wound the same way so overlaps fill as one.
- `Path::stroke(points: &[Point], s: Stroke) -> Path`: The line through `points`, ready for `PaintCx::path`; see [`stroke`].
- `struct Shape(pub(crate) Rc<ShapeData>)`: A [`Path`] stored on the GPU once, like a glyph, and drawn into any rect with `PaintCx::shape`: scaling it costs nothing.
- `Shape::from_bytes(bytes: &[u8]) -> Option<Shape>`: A shape written by the `svg2path` tool, usually `include_bytes!`d; `None` if `bytes` aren't one or are truncated.
- `Shape::new(path: Path, view: Rect) -> Shape`: `path` with `view` as the box that `PaintCx::shape` maps onto its target rect, like an SVG `viewBox`.
- `Shape::view(&self) -> Rect`: The box mapped onto the target rect when drawn.
- `Shape::path(&self) -> &Path`: The outline, in the coordinates of `view`.

### src/render/gpu.rs

### src/render/primitives.rs

- `struct Color`: An sRGB color with straight alpha, each channel in 0..=1.
- `Color::hex(rgb: u32) -> Color`: sRGB `0xRRGGBB`.
- `Color::alpha(self, a: f32) -> Color`: The same color at opacity `a`, replacing the current one.
- `Color::mix(self, to: Color, t: f32) -> Color`: `self` at `t` 0, `to` at `t` 1, blended per channel, alpha included.
- `Color::lighten(self, t: f32) -> Color`: Moves `t` of the way to white, keeping alpha.
- `Color::darken(self, t: f32) -> Color`: Moves `t` of the way to black, keeping alpha.
- `struct Rect`: An axis-aligned box in logical px, y growing downward.
- `Rect::new(x: f32, y: f32, w: f32, h: f32) -> Rect`: A box with its top-left corner at `x`, `y`.
- `Rect::contains(&self, x: f32, y: f32) -> bool`: Whether the point is inside: left and top edges count, right and bottom don't.
- `Rect::intersect(&self, o: &Rect) -> Rect`: The overlap of both boxes; zero-sized where they don't meet.
- `Rect::union(&self, o: &Rect) -> Rect`: The smallest box containing both.
- `struct Pixels`: A rendered frame: sRGB RGBA8, row-major.

### src/runtime/embed.rs

### src/runtime/task.rs

- `struct Notifier(Arc<Notify>)`: Asks the UI to rebuild, from any thread: worker threads hold clones and call `notify` after changing data the view reads; `widgets::watch` rebuilds its subtree when that happens.

### src/source.rs

- `struct Polled<T>`: A stream from [`polled`].
- `fn polled<T: 'static, F: Future<Output = T> + 'static>(mut fetch: impl FnMut() -> F + 'static, again: impl FnMut(&T) -> Option<Duration> + 'static) -> Polled<T>`: Yields what `fetch` resolves to, then fetches again after the delay `again` picks for that result (a refresh after a success, a shorter retry after an error) until it returns `None`.
- `struct Latest<T>(Option<T>)`: Collects a stream by keeping only its newest item, for a `stream_builder` over a source that sends whole snapshots (a refreshed list) rather than pieces to append.
- `Latest::get(&self) -> Option<&T>`: The newest item, once there is one.
- `struct Cache<K, V>(Rc<RefCell<HashMap<K, V>>>)`: Values kept by key across rebuilds, e.g. per-row data a list fetches once: rows scrolled away and back build from the cache instead of fetching again.
- `Cache::new() -> Self`: An empty cache.
- `Cache::get(&self, key: &K) -> Option<V>`: A copy of the value under `key`; wrap large values in `Rc`.
- `Cache::insert(&self, key: K, value: V)`
- `Cache::remove(&self, key: &K)`: Forgets `key`, so its next build fetches again.
- `Cache::clear(&self)`
- `fn cached<K, V, F, E>(cache: &Cache<K, V>, key: K, fetch: impl FnOnce(Scope) -> F + 'static, build: impl Fn(Option<&V>) -> E + 'static) -> Element`: Builds from `cache`'s value for `key`, or, while there is none, from a `future_builder` over `fetch` that stores what it resolves to under `key`.

## dfui-map

### map/src/lib.rs

- `struct MapBuilder`: Collects areas and lines in metres around an origin and packs them into [`MapData`].
- `struct Layer(usize)`: One of a [`MapBuilder`]'s layers.
- `MapBuilder::new(lat: f64, lon: f64) -> Self`: A map centred on `lat`, `lon` in degrees.
- `MapBuilder::point(&self, lat: f64, lon: f64) -> Point`: `lat`, `lon` in metres east and south of the origin; an equirectangular projection, fine for a city.
- `MapBuilder::layer(&self, color: Color, min_scale: f32) -> Layer`: A layer drawn in `color`, hidden while zoomed out below `min_scale` logical px per metre (0 always shows it).
- `MapBuilder::area(&self, layer: Layer, outers: &[Vec<Point>], holes: &[Vec<Point>])`: A filled area, e.g. an OSM multipolygon: `outers` filled, `holes` cut out of them.
- `MapBuilder::line(&self, layer: Layer, points: &[Point], width: f32)`: A line `width` metres wide through `points`, with round caps and bevelled joins.
- `MapBuilder::label(&self, layer: Layer, points: &[Point], text: &Text, font: Font, s: &str, size: f32) -> bool`: `s` at `size` metres along the polyline, e.g. a street's name inside it: centred, reading left to right, each glyph turned to the line under its middle.
- `MapBuilder::build(self) -> MapData`: Cuts every layer at each level of detail into quadtree cells of at most [`MAX_QUADS`] segments.
- `struct MapData`: Geometry ready to draw, from [`MapBuilder::build`] or [`MapData::from_bytes`].
- `MapData::to_bytes(&self) -> Vec<u8>`: The map as [`MapData::from_bytes`] reads it, little-endian: `DFM2`, the bounds as four f32; a u32 count of layers and for each its color as four f32 and a u32 of the level drawn in place of each, four bits a level; a u32 count of tiles and for each its cell as four f32, min_scale, a u32 of its layer and (high byte, 255 for labels) level and a u32 length of its geometry; then each tile's geometry as [`encode`] writes it.
- `MapData::from_bytes(bytes: &'static [u8]) -> Option<MapData>`: A map written by [`MapData::to_bytes`], usually `include_bytes!`d.
- `MapData::tiles(&self) -> usize`: The tiles across every level, for gauging how heavy a map is.
- `MapData::segments(&self) -> usize`: The segments across all tiles, each 32 bytes on the GPU once drawn.
- `fn map(data: &Rc<MapData>) -> Map`: A pannable, zoomable map of `data`: drag to pan; wheel, ctrl+wheel or pinch to zoom.
- `struct Map`: See [`map`].
- `Map::start(self, center: Point, scale: f32) -> Self`: Opens centred on `center` (from [`MapBuilder::point`]) at `scale` logical px per metre, instead of fitting the whole map.
- `Map::focus(self, focus: Option<(Point, f32)>) -> Self`: Centres on `center` and zooms in to at least `scale` whenever this differs from the focus of the last build, e.g. to show a search result.
- `Map::fit(self, bounds: Rect) -> Self`: Fits `bounds` (in [`MapBuilder::point`] units) to the widget, zooming in or out, whenever they differ from the last build's, e.g. to show one region and then the whole map again.
- `Map::overlay(self, f: impl Fn(&mut PaintCx, &dyn Fn(Point) -> Point) + 'static) -> Self`: Paints over the map, given a function from map points to logical px, e.g. to draw markers that keep their size while zooming.
- `Map::on_tap(self, f: impl Fn(&mut EventCx, Point) + 'static) -> Self`: Runs on a tap that didn't pan or pinch, with the map point under it in [`MapBuilder::point`] metres.
